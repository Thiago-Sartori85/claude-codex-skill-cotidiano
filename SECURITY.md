# Segurança / Security

## Português
- Repositório público: **não publique** credenciais, tokens, dados pessoais, familiares ou de patrimônio, ou material de projetos privados.
- Forks não concedem permissão de escrita na origem. Pull requests não são integrados automaticamente.
- **Configure manualmente** uma proteção para a branch `main` em GitHub → Settings → Rules → Rulesets (ou Branches, conforme plano), restringindo escrita e merge a pessoas autorizadas. **CODEOWNERS sozinho não aplica essa regra.**
- Audite `SKILL.md`, arquivos ocultos, scripts, dependências, prompts e links antes de aceitar uma contribuição.
- O conteúdo inicial desta skill é exclusivamente Markdown e **não executa scripts**.
- Para reportar falhas de segurança, use contato privado do mantenedor no GitHub e não issues públicas com segredos.

## English
Public skill repository: never publish credentials, personal/family/asset records or private project materials. Forks cannot write upstream. External PRs require explicit maintainer review. Protect `main` using GitHub branch rulesets; **CODEOWNERS by itself is not enforcement**. Audit instructions, hidden files and executable content before accepting changes. The initial skill is Markdown-only, with no executable scripts.
